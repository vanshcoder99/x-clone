# X Clone

A full-stack Twitter/X clone built with the PERN stack (PostgreSQL, Express, React, Node.js), Prisma ORM, and TypeScript. Includes an AI-powered tweet suggestion feature using an LLM API.

## Tech Stack
- Frontend: React, TypeScript, React Router
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL, Prisma ORM
- AI: LLM API integration
